# Privacy

- Unswiper works **entirely on your Mac**. It has no account, no cloud, and sends no photos or data anywhere.
- It only reads the folder you choose.
- Its own records (your decisions and commit history) are stored in `~/Library/Application Support/Unswiper`.
- Files are only moved when you confirm a commit, and only to the Trash or a quarantine folder — Unswiper never permanently deletes anything.
- **Photo Info** shows the location saved in a photo only on this Mac. It is never sent anywhere. Unswiper keeps a copy of each photo's location only in its own library file on this Mac, so it can group photos by place; place names are looked up offline; **Open in Maps** opens OpenStreetMap in your browser only when you click it. You can hide locations with **View ▸ Show Location in Photo Info**.
